01 / PROFILE

艺术家资料

从影像、声音与建筑出发，理解 Anri Sala 如何把观看变成一种身体性的听觉经验。

Anri Sala（1974 年生于地拉那）是一位以电影、影像、声音装置、音乐和建筑关系展开创作的艺术家。作品经常让一个微小的声响、一个延迟的字幕或一次屏幕错位，扩展成关于记忆、城市、制度与时间的空间经验。

他的作品不把声音当作图像的说明，而是把声音当作一种能够改变观看路径的结构：音乐会从屏幕中脱离，建筑会成为回声体，观众的行走也会成为作品的一部分。早期的采访与城市影像建立了语言、翻译和政治记忆的张力；后期的装置则把这种张力转译为可移动、可聆听、不可完全稳定的场域。

阅读方法

把每件作品看作一个“关系系统”，而不是孤立的物件：材料决定声音的传播，建筑决定观看的角度，观众的位置决定作品何时变得可听。分析重点因此落在三个层面：一是作品如何组织感知，二是作品如何带入历史，三是作品如何在不同机构与城市中重新适配。

这也是为什么作品和展览不能被完全分开：同一件作品在新的地点会改变节奏、路径和身体尺度；展览并不是作品之外的包装，而是作品继续生成的条件。

WORK / 2026

没有窗户，不要哭（莉娜·博·巴尔迪：玻璃屋） / No Window No Cry (Lina Bo Bardi, Casa de Vidro)

玻璃、金属窗框、音乐盒；2026；尺寸依建筑版本而变

这是 Sala 的《No Window No Cry》系列在 2026 年的最新版本之一，作品将现代主义建筑的窗框、玻璃与音乐盒结合起来。Esther Schipper 的作品页列出 Lina Bo Bardi 的 Casa de Vidro 版本，并说明系列中的窗户会随着建筑而变化，而歌曲保持不变。窗框因此既是观看现实的界面，也是把建筑历史、身体尺度和声音记忆重新带入展厅的装置。

展开作品分析

作品的重要性在于，它不把建筑当作单纯的背景，而是让每一扇窗都成为一次具体的空间翻译：同一首歌在不同建筑中保持连续，窗户的结构、视线和历史却不断改变。2026 版本把现代主义建筑的透明性与音乐盒的机械性并置，使观看不再是远距离的凝视，而成为一个需要伸手、靠近并重新定位的动作。作品由此延续 Sala 对声音、记忆和建筑关系的研究，同时把系列推向新的地点与新的现代主义谱系。

提取词｜窗／建筑／音乐盒／现代主义时间

WORK / 2021

时间不再 / Time No Longer

沉浸式声音、光线与旋转空间；Messiaen《时间终结四重奏》

作品围绕 Messiaen 的《时间终结四重奏》展开，把音乐、旋转、光线和展厅路径组合为一个不断调整的感知系统。唱盘在近似失重的视觉条件中运行，唱针偶尔跳针、悬停或改变轨道，音乐因此同时指向物理旋转和历史创伤。作品既可作为单件 13 分钟的计算机生成影像与多声道装置观看，也会随着建筑尺度和观众移动重新组织。

展开作品分析

时间在作品中既是音乐标题，也是观众身体被迫面对的物理条件。旋转并不提供全景，而让空间持续拒绝稳定的正面；Messiaen 的音乐从被囚禁的历史中进入展厅，形成一种不稳定却持续抵抗的当下。作品的重要性在于，它把监禁中创作的《时间终结四重奏》与太空舱、失重唱盘和圆形建筑并置，让线性历史被改写为断裂、循环和漂浮的时间经验；Pinault 的展览进一步把这件作品延展到通道、橱窗、放映和现场萨克斯演出，使“时间”成为机构、建筑、声音和观众共同承担的展览结构。

WORK / 2019

随着你前行 / As You Go

多屏影像／声音装置；钢琴键盘、手指和空间错位

作品以多块相互错开的屏幕呈现手指在钢琴键盘上的运动。图像中的手势、键面和屏幕之间彼此延迟，观众必须在空间中移动，才能把一组局部画面暂时拼合为一次演奏。艺术家档案将其列为 2019 年的重要作品，并记录其在 Castello di Rivoli、Fundación Botín 及台北 Winsing Art Place 等地的展览延展。

展开作品分析

作品让“前行”成为观看动作，而不只是标题中的方向。手指似乎在弹奏同一架钢琴，但屏幕的错位阻止观众获得完整的正面；每一步移动都会重新安排声音与图像的对应关系。作品的重要性在于，它把 Ravel 系列中关于双重时间的研究转译为更开放的空间语法：不再只是两条影像并置，而是让观众的身体参与拼接、校准和误读。于是，演奏不是一个已经完成的动作，而是在观看者行走时不断被重新生成的关系。

提取词｜屏幕错位／行走／键盘／拼接

WORK / 2018

仅当且仅当 / If and Only If

视频；蜗牛、弓与中提琴；Stravinsky《Elegy for Solo Viola》

镜头跟随蜗牛沿弓的长度移动，同时由 Gérard Caussé 演奏 Stravinsky 的独奏中提琴作品。身体尺度、速度和音乐持续时间被放在同一个实验里；Esther Schipper 的作品资料还记录了以蜗牛和弓为图案的木制纺织印版，说明影像中的偶然行动被进一步转译为可触摸的雕塑和图像。

展开作品分析

作品的戏剧性来自极慢的速度：蜗牛不是比喻，而是一种具体的时间装置。弓被重新看成一条地形，音乐的优雅与爬行的迟缓互相校准；观众必须把注意力交给几乎不动的身体，才能听见速度本身。作品的重要性在于，它把演奏者的技术、乐器的物质性和非人身体的偶然性放在同一条因果链上：蜗牛每一次停顿都改变弓与弦的关系，也使“音乐作品”的权威暴露为可以被另一种生命尺度重新编排的过程。

提取词｜微观身体／弓／速度／音乐时间

WORK / 2017

拉威尔·拉威尔：间隔 / Ravel Ravel Interval

双通道影像／声音装置的重新适配；两位钢琴家的左手协奏曲演奏

作品沿用 Ravel 左手钢琴协奏曲的双重演奏结构，但把两条时间线重新拉入具体展览空间。Marian Goodman 与 MMFA 的资料说明，Louis Lortie 与 Jean-Efflam Bavouzet 的演奏从同步开始，随后分离、重合、漂移，再次恢复同步；“interval”因此既是屏幕之间的距离，也是观众行走和停留所经历的时间。

展开作品分析

Ravel Ravel Interval 把原本属于剪辑和演奏的差异扩展成一段空间经验。观众不再只是在两块屏幕之间比较速度，而是在移动时感到自己的停留长度如何改变两条时间线的关系。作品的重要性在于，它把“同一首曲子”的问题推进为“同一件作品能否在迁移中保持同一”的问题：每次重新适配都保留核心结构，却让建筑、演奏者、距离和观众共同写入新的版本。

提取词｜间隔／再适配／钢琴／观看距离

WORK / 2017

最后的避难所 / The Last Resort

38 个倒置小军鼓、风、光影与 Mozart 单簧管协奏曲

作品最初在 Sydney 的 Observatory Hill 呈现。38 个倒置的鼓被悬挂在 Rotunda 中，鼓面成为反射光线和海港景观的圆形碎片；风改变鼓的方向，附着的鼓槌产生各自的节奏，Mozart 协奏曲则成为关于自然、历史、启蒙与殖民视角的声音线索。Kaldor 的资料还说明，作品曾在纽约、莫斯科和卢森堡被重新呈现，地点迁移本身构成作品的一部分。

展开作品分析

作品把“风景”变成会发声的装置：自然力量并非被观看的背景，而是主动改变物件的节奏和排列。标题中的 resort 既像避难所，也像一种无法真正抵达的退路；经典音乐在新的地点中被迫承受距离、漂流和历史的重量。作品的重要性在于，它把一件西方启蒙音乐的“杰作”置于澳大利亚殖民史和原住民文化被驱逐的现实中，以风和航海日志改变协奏曲的速度与流向；因此它既是声学雕塑，也是关于地点、文化权力、跨海迁移和公共艺术责任的历史装置。

提取词｜风／鼓／自然／殖民与启蒙的历史视角

WORK / 2017

一切颤动（幻觉／退化） / All of a Tremble (Delusion/Devolution)

墙纸图案绘画、手工压印与由滚筒／钢齿构成的声音装置；尺寸依展览而变

作品从旧式墙纸图案出发，把重复的装饰纹样转译成大幅纸面和可发声的滚筒结构。相关展览资料说明，Sala 以铅笔把图案压印到墙纸上，再把图案的两半组合进滚筒，使滚筒在钢齿上运动时成为一种音乐盒。图像、手工压力、历史样式和机械声音因此在同一件作品中相互转换。

展开作品分析

作品的核心不是把绘画附加一个声音效果，而是让图案本身变成声音的谱面。墙纸原本承担重复、覆盖和室内装饰的功能；当它被压印、切分并重新组合，重复就显出身体劳动和机械节奏的差异。作品的重要性在于，它把装饰性材料从“背景”提升为一种会组织时间的系统：观众既看到图案的扩散，也听见滚筒把历史样式转成不稳定的旋律。由此，Sala 将视觉秩序、手工动作和机械演奏放到同一条关系链中，继续推进他对“声音如何从物件和空间中生成”的研究。

提取词｜墙纸／图案／滚筒／手工压力

WORK / 2017

接管 / Take Over

双屏视频；钢琴键盘、人工手势与程序化动作

作品以两个屏幕呈现钢琴键盘：键面可以被人的手触发，也可以被程序控制。Pinault Collection 的项目资料将其描述为一件双屏视频作品，并把它放入与《时间不再》相连的展览路径中。键盘既是乐器，也是一个可被编程、重复和接管的动作界面。

展开作品分析

“接管”首先发生在手势层面：观众看到手指造成声音，却不能确定动作是否仍由人的意图控制。双屏结构把真实演奏与程序化动作放在同一平面，使音乐的作者性变成一种需要持续辨认的关系。作品的重要性在于，它把 Sala 一贯关注的身体、机械和时间差推进到数字控制的层面：手指不再只是表达音乐，而成为可以被复制、预设和替代的接口；当作品进入 Bourse de Commerce 的展览网络时，它又与《时间不再》的旋转唱盘、现场音乐活动形成对照，让“谁在演奏”成为关于技术、身体和机构的共同问题。

提取词｜键盘／程序／手势／作者性

WORK / 2016

没有窗户，不要哭（奥拉沃·雷迪格·德·坎波斯：IMS） / No Window No Cry (Olavo Redig de Campos, Instituto Moreira Salles)

音乐盒、玻璃、金属窗框；2016；具体尺寸依展览版本而变

Instituto Moreira Salles 2016 年展览的作品清单明确列出这一版本：音乐盒、玻璃与金属窗框，署名为 Olavo Redig de Campos 设计的 IMS 建筑版本。作品把建筑窗景与一段可被启动的旋律结合起来，观众面对的不是被动的窗，而是一件既框取景观、又把声音嵌入建筑界面的装置。

展开作品分析

这一版本说明《No Window No Cry》并不是一个固定物件，而是一套会随建筑迁移而改变的关系系统。IMS 的展览文本强调，Sala 让声音与建筑共同组织观众的 circulation，并通过照片、物件和声音影像把观看推进到“当下”的感知经验中；窗框因此同时承担了取景、记忆和发声三个功能。2016 版本的重要性在于，它把现代主义建筑的视觉框架转成可被身体触发的音乐界面，让景观不再只是被观看的对象，而成为会被声音重新书写的现场。

WORK / 2014

当下时刻（降B调） / The Present Moment (in B-flat)

影像、声音与空间性装置

作品把音乐、瞬间和空间的关系推向更强的现场性：现在不是一个点，而是由声响、光线和观众位置共同生成的持续区间。标题中的降 B 调既是音乐提示，也是一个无法脱离身体听觉的空间条件；作品让观众在声源、屏幕和停留之间感到“当下”正在被制造。

展开作品分析

它延续了 Sala 对“现在”的怀疑：我们听到的当下总被刚刚过去的声音和即将到来的声音包围。作品的现场性不在于制造一个新的事件，而在于让观众意识到自己总是在一个已经开始、也尚未结束的声学过程里。它的重要性在于把时间从影像的叙事顺序中释放出来，使观众不能只靠观看画面理解作品，而必须用身体测量持续、回声和缺席，从而连接 Sala 早期关于记忆的影像与后期关于空间声场的装置。

提取词｜当下／持续／声学空间

WORK / 2013

拉威尔·拉威尔·拆解 / Ravel Ravel Unravel

双通道影像装置；Ravel 左手钢琴协奏曲的两种解释

两种演奏、两个速度和两条影像时间线相互靠近又彼此错开。作品围绕 Ravel 的左手钢琴协奏曲展开：这首作品为第一次世界大战中失去右臂的钢琴家 Paul Wittgenstein 而作，Sala 将两位演奏者的左手、屏幕和节拍关系拆成可被观看者穿越的空间结构。

展开作品分析

“unravel”不是把乐曲拆坏，而是让被认为固定的作品显出内部的弹性。观众在两个屏幕之间移动时，也被迫在两种时间之间作出选择；作品把演奏差异从音乐内部推向观看者的身体。作品的重要性在于，它以一件经典音乐作品为材料，却不把经典当作需要被忠实保存的对象，而是揭示演奏、技术、身体限制和观看位置如何共同决定我们所听见的“同一首曲子”；差异因而成为一种伦理性的观看练习。

提取词｜双重／节奏／差异／选择

WORK / 2011

没有红色的1395天 / 1395 Days Without Red

电影／影像；Sarajevo 的城市路径与战争记忆

作品以 Sarajevo 的城市移动和日常路径为核心，把战争记忆放入城市空间、路线和身体的连续性中。1395 天既是时间计量，也是一个人在城市中反复穿越危险和等待的尺度。作品不依赖历史说明片的旁白，而是让交通、道路、建筑、停顿和颜色限制共同构成一种被战争重新编排的日常感知。

展开作品分析

作品不把战争变成远景背景，而让城市的道路、建筑和等待成为记忆的载体。行走本身带有风险感，时间因此拥有政治重量；观众被迫注意那些看似平常、却被历史重新标记的城市转角。它的重要性在于将战争记忆从“过去发生过的事件”转化为持续影响当下行动的空间条件：城市仍在运行，但每一次经过、绕行和等待都携带着无法被完全看见的历史压力。

WORK / 2010

冲撞 / Le Clash

影像／声音；现场冲突与节奏结构

作品以 clash 为方法：不同声音、动作或观看角度彼此重叠，却不被整齐地合并。它可与同展览中的 No Window No Cry 对读：电影里的音乐在实体音乐盒中获得另一种生命。作品围绕 The Clash 的歌曲“Should I Stay or Should I Go”展开，在废弃的演出场所、桶式风琴和音乐盒之间，把流行音乐的记忆改写成不稳定、带有摩擦的机械演奏。

展开作品分析

冲突在这里不是戏剧性高潮，而是形式结构。观众必须在不同时间层之间寻找可听见的连接，作品因此把“理解”变成主动调频；声音的失败并没有被修复，而是被保留为观看的条件。作品的重要性在于，它把一首广为流传的歌曲从文化记忆中拆出，再通过机械装置、公共空间和现场动作重新分配作者性：熟悉的旋律仍可被辨认，但它已不再属于一个稳定的原唱或单一历史，而成为不同身体和物件共同制造的偏差。

WORK / 2008

回答我 / Answer Me

影像装置；建筑内部的声音与视觉对位

作品把一座废弃的 Buckminster Fuller 设计监视站变成声学装置。独特的圆顶建筑不是背景，而是决定声音如何被反射、分隔和定位的结构；人物、鼓、建筑回声与没有被完整听见的对白被置于同一场景中，使“回答”既指向语言，也指向空间是否能够回应人的行动。

WORK / 2003

一遍又一遍 / time after time

影像作品；时间、重复与观看节奏

作品在 Tirana 的道路上呈现一匹消瘦的马：车辆经过时，它抬起一只蹄子，却始终停留在原地。标题把观看引向循环，也把身体的停滞与城市转型并置。道路、汽车和动物共同组成一种简短却持续回返的城市动作，作品拒绝把停顿解释为单纯的等待或象征，而让观众在每一次重复中重新确认身体与环境的关系。

展开作品分析

作品可作为 Sala 后续“时间差”方法的早期入口。这里的时间不是线性叙事的容器，而是让观众察觉到观看本身正在改变；每一次车辆经过都像一次被触发却没有完成的逃离。它的重要性在于将最小的动作发展成一种叙事结构：没有事件被真正推进，但城市的速度、动物的迟缓和观看者的期待不断互相校准，后续作品对延迟、循环和不稳定当下的关注由此获得清晰的早期形式。

提取词｜重复／延迟／记忆的偏移

WORK / 2003

给我色彩 / Dammi i colori

视频作品；城市景观、颜色计划与政治语境

作品把 Tirana 的城市颜色、公共空间和政治改革放在同一条视觉—制度链上。颜色不是装饰，而是城市治理和集体记忆的表层；它也把艺术家与 Edi Rama 的合作关系带进城市改造的叙事。镜头在城市景观、谈话和公共建筑之间移动，使颜色计划同时呈现为审美策略、政治沟通和对旧制度痕迹的覆盖。

展开作品分析

WORK / 1998

访谈（寻找词语） / Intervista (Finding the Words)

彩色视频投影、立体声；26 分钟；尺寸可变

早期作品以采访为形式，让语言的断裂成为影像结构：说话者、字幕、记忆和政治历史之间没有完全重合。字幕不是解释，而是把“说过的话”变成会迟到、会缺席的视觉层。作品将私人叙述置于后共产主义 Albania 的社会记忆中，纪录性方法因此不等于客观记录，而是让被访者、翻译和观看者共同面对无法完整复原的过去。

展开作品分析

这件作品的关键不是“讲述一个过去”，而是让观众感到词语如何在个人记忆中失去同步。母亲的回忆、被遮蔽的历史和字幕之间始终留有缝隙；后期作品中的延迟、重复和声音错位，可以在此找到语言层面的前史。它的重要性在于把 Sala 的核心方法提前确立：声音不是为图像提供说明，而是揭示历史叙述中始终存在的缺口，让观看转变成对翻译、记忆和证词可靠性的主动判断。

提取词｜语言／字幕／失语／记忆

Serpentine：展览作为循环的声学结构

Serpentine 的循环结构把作品对、现场表演和可被触发的装置组织成一个不断返回、错位和重新开始的观看过程。

分析固定影像提供记忆，现场演奏带来偏差；观众每次重新进入都会改变对前一次声音的理解，循环因此是差异的累积。

REVIEW / INSTITUTION TEXT

Kurimanzutto：If and Only If 的旅行与表演

Kurimanzutto 把 If and Only If 描述为一场 voyage and performance：Stravinsky 的《Elegy for Solo Viola》与蜗牛成为缓慢二重奏，迫使中提琴手改变速度和乐句。

分析蜗牛不是象征性道具，而是改变音乐结构的参与者；表演在弓、弦、蜗牛速度和摄影观看之间形成。

Bourse de Commerce：Take Over 与程序化手势

项目资料把 Take Over 说明为双屏视频：钢琴键盘既能被人的手激活，也能被程序控制；它与 Time No Longer 的旋转唱盘和现场活动组成同一条展览路径。

分析作品让作者性从个人表达转成技术、身体和制度之间的协商；观众也被迫持续判断谁在演奏。

Marian Goodman：Time No Longer 展览文本

画廊资料将 Time No Longer 与 Surface to Air、Noli Me Tangere Inversa 等作品并置，继续讨论光、表面、时间层与空间感知；旋转唱盘与 Messiaen 的《时间终结四重奏》相遇。

分析展览文本的价值在于，它把一件作品从单独的旋转影像扩展为一组关于表面、云、沉积岩、壁画和不同时间尺度的空间关系。
